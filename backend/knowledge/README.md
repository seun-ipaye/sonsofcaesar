# Support knowledge base

Source documents for the support agent. Each `.md` file here, except this one,
gets indexed for retrieval, and each `##` section is meant to stand alone as an
answer.

Rules:

- Only write what is true of the live site or is a policy the organizers confirmed.
- If something is unknown, leave it out. The agent hands those questions to @socfrvr.
- Never put a secret address, door code, ticket code, customer detail or any
  other private information here.
- Dates, prices and availability come from the live event data, not these files.
